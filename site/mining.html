This miner serves session-serving mode (Mode A, chain-settle) on the FLOP devnet: buyers open sessions, the worker answers with the registered model, and settlement happens on-chain. Devnet FLOP is test value — the official docs state devnet earns no rewards and no airdrop weight; it exists to prove the setup before testnet. Stake shown is network-sponsored, not ours. "Verified jobs" and the calibration cap are chain-side facts reported by the worker. Data from /mining.json, refreshed every 5 minutes by flop-mining.py; "worker image" is checked against flop.network/releases.json — a stale image gets fenced by runtime upgrades.
