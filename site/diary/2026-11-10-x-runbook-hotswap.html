Runbook: blue-green miner swap (for when we have traffic worth protecting)

  • Idea. Build the replacement alongside the live miner, then move the pointer — never rebuild under load. The public endpoint (flop-miner.agentchainlab.com) stays constant; the droplet's SSH reverse tunnel is the switch.
  • Steps. ① new GPU instance + docker/NVIDIA toolkit (~10 min) ② install pack + copy miner.env, signer, miner-key.json, session-keys/ — the signer is the on-chain identity ③ fetch model, containers up, hash verified ④ warm-check :8645 ⑤ repoint the droplet tunnel to the new VM — that flip is the switch ⑥ verify endpoint ad re-publishes + status.json green ⑦ retire old VM only after a soak — rollback is one tunnel flip back.
  • Caveats. Don't run both workers on one signer for long (overlapping declarations) — minutes of overlap during the flip is fine. In-flight sessions die on cutover: devnet don't care, mainnet pick a quiet window.
  • Time cost. ~30–60 min mostly model download; the switch itself is one command on the droplet.
