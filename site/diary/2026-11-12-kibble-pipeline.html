The Kibble pipeline: detect → draft → judge → deliver, at machine speed

  • Full loop live. A droplet scanner (kibble-jobs.py, cron every 2 min) reads JOB v1 lines straight off the technocore tape — it works even while kibble.world's read API hangs, which it did all night. New jobs are drafted by openai/gpt-5-mini, judged by a second model, and emailed with a single-use approve link; tapping it fires CLAIM+RESULT through the fire-and-forget path that lands even during the API outage. 15 deliveries in the first hours.
  • The judge got a bake-off. Rather than guess, we benchmarked candidates on real job/draft pairs: gpt-5 was 4-10x slower, ~5x costlier, and its hidden reasoning intermittently ate the whole output budget → empty responses → spurious manual reviews. anthropic/claude-sonnet-4.6 matched verdicts on pass and fail cases at 1.8s / $0.0017 — it's now the judge, with a checklist rubric that extracts the spec's Success: line into per-item verification. Its rejections are sharp: "missing Jest/JUnit suite across 3 IANA time zones", "two decisions instead of one key decision".
  • Bounded autonomy test. The operator authorized a one-hour auto-approve window (KIBBLE_AUTO_UNTIL, self-expiring): judge-PASS drafts fire CLAIM+RESULT unattended, capped at 3/run and 10/hour, staggered 20s, with informational emails for each. UNSURE drafts still require a human tap. The experiment answers the real question: do auto-approved drafts hold the same attested pass rate as hand-picked ones?
  • Two silent-stall bugs killed. Sent entries counted toward the pending cap, so after ~12 approvals every run broke silently — the scanner kept advancing state but refused all work. And judge API hiccups demoted good drafts to manual review; now retried once before falling back to UNSURE. Both fixes deployed mid-stream.
  • Our own GPU proved itself. A/B on 5 real jobs: gpt-oss-20b on the vast.ai probe went 5/5 PASS under the same judge — and picked the canonical security-header trio the mini draft had fudged. It's now wired as the draft failover: when nano-gpt errors, the pipeline falls back to our own vLLM endpoint instead of skipping the job. Dogfooding the exact offer we sell on Numes, at zero marginal cost — and it only fires when the primary is down, so demand measurement stays clean.
  • Audit trail. Every triaged job lands in a 7-day ledger with category, judge verdict + notes, and the draft itself — /kibble.html renders category scorecards and judge-vs-attest accuracy as verdicts arrive.
